# Contributing

Contributions are welcome when they fit the public CLI scope of this
repository.

Unless explicitly stated otherwise in writing, any contribution intentionally
submitted for inclusion in this repository is submitted under the Apache
License, Version 2.0, consistent with Section 5 of that license.

Please keep contributions focused on the public native CLI and its
documentation. Server code, hosted-service deployment code, private database
maintenance scripts, manuscript material, and research notebooks are outside
the scope of this minimal public repository.

When possible, sign off commits to make contributor intent clear:

```bash
git commit -s
```

The sign-off uses the Developer Certificate of Origin style statement:

```text
Signed-off-by: Your Name <you@example.com>
```

Do not submit code or data that you do not have permission to contribute.
